# StoryForge · 短剧工坊

对话驱动的 AI 短剧工作台。你说一句想拍什么，模型把它翻译成节点图，本地内核负责执行（生成直连火山 ARK），画面回到工作台。

> 不是"人画流程图"，是"模型写流程，人审流程"。

---

## 定位：它是生成机，不是剪辑软件

一句话：**把一句话的构想，变成一组能直接用的镜头素材。**

它管的四件事，到"素材落盘 + 交付一个文件"为止：

| 环节 | 在这台工具里 |
|---|---|
| 听懂 | 对话 → 分镜计划（镜别、运镜、台词、时长） |
| 变成能执行的图 | 画布上的节点图，人和 AI 改的是同一张 |
| 真跑出来 | 原生内核执行（生成直连 ARK），逐镜进度、逐镜耗时、随时能停 |
| 交得出去 | 分镜板按镜看、单镜重跑、按出片顺序合成一个文件 |

它**不碰**的（判断标准只有一条：**要不要在时间轴上编辑？要，就不做**）：

| 不做 | 为什么 |
|---|---|
| 剪切 / 变速 / 关键帧 / 转场 | NLE 的活，做不过 Premiere / 剪映，做了也没人用 |
| 字幕烧录 / 音轨替换 / 混音 | 同上；要字幕就把台词导出给剪辑软件，别在这里长出一条轨道 |
| 调色 / 滤镜 / 特效 | 属于生成端（提示词、模型），不属于后期 |
| 时间轴预览 / 多轨 | 一旦出现轨道，这工具就成了"又一个剪辑软件"，定位就散了 |

边界内保留的两件事，因为它们是**排序和封装**，不是编辑：

- **出片顺序**：拖一下改镜头先后，纯排序，不产生时间轴；
- **合成成片**：把同一版的多段镜头按顺序无损拼成一个文件，省得自己回去拼。

再往上就该交给剪辑软件了——这不是能力问题，是分工问题。

## 目录

整个产品就是仓库本身：前端、桌面壳、执行内核、文档、脚本全在根目录下，不引用外部目录。

```

├── src/                         前端（React + TypeScript）
│   └── lib/node-library.json    内核节点目录（12 节点白名单）
├── src-tauri/                   桌面壳 + 原生执行内核（Tauri + Rust）
│   └── src/kernel.rs            图解释器 / ARK 直连 / ffmpeg 杂活
├── bin/                         ffmpeg + ffprobe（随包分发，不入库）
├── engine/
│   ├── prompts/                 提示词资产（风格圣经 / 分镜语法 / 负面词，可编辑）
│   └── workspace/               工作区
│       ├── input/ output/ temp/ 运行时数据
│       └── models/              空目录（生成全在云端）
├── docs/
│   ├── architecture.md          现行架构方案
│   ├── reference/               火山方舟接口参考
│   ├── archive/                 历史方案 v1 / v2 / v3（ComfyUI 内核时代）
│   └── shots/                   运行截图
└── scripts/                     构建与测试脚本
```

根目录就是产品本体：`README.md`、`启动StoryForge.bat` 和全部源码。

## 首次运行

**安装包（推荐）**：从 [Releases](../../releases) 下载 `StoryForge_x.y.z_x64-setup.exe`，双击安装即用——内核、ffmpeg 全部内置，无需 Python、无需 ComfyUI、无本地模型。

**开发模式**：

```powershell
cd app
pnpm install
pnpm tauri dev
```

内核常驻，没有"启动引擎"这一步，打开就能生成。

## 配置模型

点右上角「设置」，两个 Key 分开填：

| 字段 | 说明 |
|---|---|
| 对话 Base URL | DeepSeek：`https://api.deepseek.com/v1` |
| 对话 API Key | `sk-...`，只存本机，用来做策划和分镜 |
| 对话模型 | `deepseek-flash`（需支持 JSON 输出） |
| ARK Key | `ark-...`，生图/生视频使用；改完保存即生效，无需重启 |
| 图像/视频模型 | 节点调用时使用的生成模型 |
| 视频分辨率 | 480p / 720p / 1080p（1080p 是 10bit H.265） |
| 同步音频 | 是否让 Seedance 生成对白 / 环境声 |
| 预算 | 单次最多镜头数、总时长上限（秒）；超限自动截断 |
| 项目根目录 | 留空自动识别；移动项目后无需改任何路径 |

ARK Key 也可以读环境变量 `ARK_API_KEY`（内核每次提交前都会读一次配置）。

## 现在能做什么

- **正常聊天**：打招呼、问用法、闲聊都行，不再逼你拍片
- **多会话**：导演台左上角可切换/新建/删除对话，重启应用历史不丢（产物按端口自动重连）
- **界面手感**：导演台可拖拽调宽、`Ctrl+B` 收起；分镜看大图支持 `←` `→` 翻页、`Esc` 关闭；运行中显示阶段 + 已用时
- **流式对话**：正文边生成边显示（不等整段 JSON 落完）；`思考` 折叠成一行、点开看模型的 reasoning 原文；工具调用按步列出来（读取角色锚点 / 编译节点图 / 校验连线 / 执行 ComfyUI），每步带结果和耗时，点开看原始输出
- **失败不糊弄**：配了 Key 却调不通就直说原因（Key 无效 / 模型名不对 / 超时），不再悄悄退回占位图；设置页有「测试连接」按钮，一次最小请求验证 Base URL + Key + 模型 ID
- **对话只管说话，动手全在画布**：说一句想拍什么，模型把分镜编译成节点图直接放到画布上；你要改什么（换景别、改时长、加节点、改连线、调参数）也直接说，它自己在图上改。对话区里不摆参数、不摆确认卡
- **画布是唯一真相**：AI 改的是这张图，你改的也是这张图，执行的就是屏幕上这张图——只有画布上一个「开始生成」按钮会真的花钱，AI 不会偷偷执行
- **开放画布（M3）**：画布页是主界面，永远可编辑，不拍片也有空白画布可玩——从 394 个可执行节点里搜索添加、删除任意节点、拖端口改连线（类型自动校验）、选中节点在右上角检查器里就地改参数
- **画布照 ComfyUI 的手感做**：滚轮在指针处缩放（`Shift+滚轮` 横移）、空白拖动平移、空格/中键抓手、`Ctrl+拖` 框选、双击空白在光标处弹节点搜索（回车加第一个）、右键菜单（加节点/复制节点/断开全部连线/删除/适应画布/按数据流重排）、拖连线靠近兼容端口自动吸附并高亮、连线按类型上色、点连线 `Del` 删除、`Ctrl+A` 全选、`Del` 删选中、右下角缩放控件与适应画布
- **AI 干了什么看得见**：新节点一个个长出来（工具栏同时数「铺节点 3/5」，左下清单也跟着一条条长），改完的节点亮 7 秒并打上「AI 改」；清单（`+N 节点 / 改 N 处 / 连线 ±N`）点任意一条就把画布飞过去并选中那个节点；重新编译分镜会把整张图重铺，这时清单直接写「AI 重铺了整张图 · 旧 5 → 新 5 节点」，不让"改 3 处"掩盖整版被换掉
- **节点不糊脸**：可选输入默认收成一行「＋N 可选」（没接线也没填值的才收），点开再摊；一张视频节点从 14 行压到 9 行，多镜图也能整屏看清
- **跑不起来不许交**：AI 每次改完先过审计（必填输入接没接、终点存不存在、有没有悬空孤岛、类型对不对），不过就自己修一轮、最多两轮；还不行就整版撤回、画布保持原样，并把原因说清楚
- **点之前先自检**：「开始生成」点下去之前跑同一套审计，跑不起来直接拦下，并把出问题的那个节点指给你看（自动居中 + 选中 + 打开参数面板）
- **能停**：生成过程中按钮变成「停止」，点了立刻中断当前执行，画布不留半成品；AI 还在想/写的时候也能停（对话区右下角方块键，或让它跑飞了按一下），掐断模型输出、这一轮整版作废、画布一个字都不动
- **生成中看得见跑到哪**：内核实时播报执行进度，哪个节点在跑就给它一圈亮边，跑过的打 `✓`、出错的红边标 `出错`；视频生成中每 5 秒播报一次状态（含首帧被审核拦截自动降级重试的提示），工具栏同步显示「跑 镜头1视频」，不用盯着「生成中」干等
- **分镜页也跟着跑**：生成时「分镜」页顶上摆的是这一版正在跑的镜像——每一镜按自己那组节点（`shot_N_*`）亮起来，跑着的显示百分比和底部进度条，跑完打勾，头上写「已完成 2/4 · 正在跑第 2 镜」；跑完才换成带成图的历史卡片
- **每镜花在哪，算得出来**：跑的时候按 `shot_N_*` 前缀把 `/ws` 事件切段，每镜记三样——**等**（上一镜跑完到这一镜开跑之间的空档）、**跑**（这一镜自己节点的墙钟）、**重**（同一节点被重复执行的次数）。分镜卡写「实耗 3.1s」，页脚一排「逐镜实耗」：灰条是等、亮条是跑，拖后腿那一镜一眼看得出来；同一节点跑了两次会打 `↻2`。只记真观测到的量，云端排队藏在节点内部，就不编造。
- **拍完还能改顺序**：分镜卡直接拖，拖完这一版的"出片顺序"就变了——卡片角标按新位置重排，被挪动的镜标上「原 03」，头上出现「出片顺序 02 → 03 → 01 → 04」和「恢复原序」。只改顺序：不重跑、不动文件、不花钱，「合成成片」按新顺序拼
- **多版并排对比**：同一个计划跑了几版，分镜页点「多版对比」把它们并排放——行是镜号、列是版本（最多三版），同一镜的几版摊在同一条横线上看差别；下面「挑版本」勾选想比的几版，点缩略图仍然能全屏看原图
- **闪烁对比**：多版对比里切到「闪烁」，同一镜的几版在同一个视口里每 1.2 秒轮一版（最新在前，没有产出的版自动跳过），差别变成动态的；点「定格」停住当前版看细节，再点恢复轮播
- **测试产物清理**：资产页一键「清理测试产物」——output/ 里没被任何执行记录引用的冒烟测试文件（demo_/test_/final_check_ 等）移进 `output/_trash/`，不真删、随时可捞回。
- **缩略图不靠引擎活着**：产物文件在 `output/` 里，历史里的图和视频直接从磁盘读（本地文件协议），重启应用之后照样能看
- **智能体同等编辑权**：对模型说"把 #3 直接连到 #1"，它通过 ops 操作协议（add/remove/connect/disconnect/set/setMeta）直接改图——和人用同一个操作引擎；改完就停在画布上等你看，不自己执行
- **自我完善**：执行失败自动把错误喂回模型修订（计划路径修计划、画布路径用 ops 打补丁保留手改，最多 1 次），内核自审发现也自动沉淀；经验记忆之后每次出计划都带着，越用越顺
- **确认门 + 预算上限**：确认卡片显示镜头数、总时长与金额估算区间（超单次金额上限着警示色）；设置里可限单次最多镜头数和总秒数，超限自动截断
- **单镜重跑**：分镜板每张卡可只重跑那一镜，不用整片重来
- **往现有分镜后面加镜**：对话里说"加一个镜头"，新镜接着现有镜号编译、直接并进画布——旧镜的图和连线原样保留（同名角色复用已有定妆节点、自动接上上一镜尾帧），不再整版重铺
- **分镜表导出**：分镜板一键「分镜表」，按出片顺序导出 CSV（镜号/景别/运镜/场景/动作/台词/时长，UTF-8 BOM，Excel 直接打开），进项目 `export/`，交给剪辑软件当台词清单
- **项目数据带保险**：`project.json` 每次落盘前自动轮换出最近 3 份备份（`project.json.bak1/2/3`），误覆盖可捞回
- **尾帧接续**：多镜时上一镜尾帧自动作为下一镜的画面衔接参考
- **用量统计**：每次执行记录用了多少 LLM token、几张图、几秒视频；资产页有累计用量
- **成片拼接（M5）**：分镜板一键「合成成片」——多镜头按顺序重编码拼接（ffmpeg，crf18），成片自动进分镜板和资产页可直接播放；分镜卡支持删除记录、一键打开输出目录
- 短剧领域节点：角色定妆、分镜首帧、镜头视频、尾帧接续
- 没有 ARK Key 也能跑通链路：使用内置 `EmptyImage` 占位图（ffmpeg 生成），真实经过内核执行
- 节点目录即白名单：内核只执行 12 个自研/基础节点，目录外的 class_type 在提交时被拒收

## 协作模式

吸取 ComfyUI（节点即一切）和 DSH（一切皆插件/操作）的思路，人机协作建立在一个共识上：**图操作引擎只有一份**。

| | 人 | 智能体 |
|---|---|---|
| 入口 | 画布拖拽 / 节点选择器 / 参数检查器 | 对话 → ops 操作序列 |
| 能力 | 加/删节点、改连线、改参数 | 完全相同的操作集合 |
| 出口 | 画布上的「开始生成」 | 没有出口：改完就停在画布上 |

对话区只负责沟通（说需求、问问题、看思考与工具调用），一切与"生成什么"有关的东西都落在画布上。

## 内核在这里的角色

生成算力在云端（ARK 的 Seedream / Seedance），本地内核常驻但极轻，只做四件事：接收画布那张图、拓扑执行、直连 ARK 生成、把产物落盘到 `output/`；像素级杂活（占位图 / 缩放 / 抽尾帧 / 拼接）交给随包的 ffmpeg。

| | 不填 ARK Key | 填了 ARK Key |
|---|---|---|
| 看画布、改图、让 AI 改图 | 照常 | 照常 |
| 本地节点（EmptyImage / 缩放 / 拼接） | 跑（免费） | 跑（免费） |
| 云端生成（出图 / 出视频） | 跑不了 | 跑（按 ARK 计费） |
| 代价 | 0 | 0（本地）+ 云端按量计费 |

没有引擎进程、没有显存占用、没有启动等待——「开始生成」点了就跑。

## 能力边界

| 已通 | 未通 |
|---|---|
| 计划 → 改参 → 确认 → 分镜图 → 视频闭环 | 云端排队藏在 ARK 任务内部，拆不出来 |
| 原生内核：常驻即就绪，无 Python / 无 ComfyUI / 无本地模型 | 目录外的 ComfyUI 节点不再可执行（内核白名单拒收） |
| **成本看得见**：确认门显示估算区间（ARK 官方价，缓冲系数 = 重跑上限的真实最坏上界），单次金额上限 observe/warn/cap 三模式，cap 执行中逐镜复核累计花费超限即停，执行后按实际花费对账（Seedream 按张 / Seedance 按秒） | 即梦按条刊例价未公开，估算用占位价 |
| **逐镜自审 + 自动重跑**：全黑/全白双条件判定（又暗又无细节才算黑屏，夜戏低均值高峰值不误判）/ 时长偏差 / 分辨率不足 / 音轨缺失判废；概率性失败自动重跑该镜（2 轮上限），确定性失败（参数级，重跑必复现）直接止损不烧钱；结果落 history.verification | 内容语义崩坏（脸崩 / 手崩）查不出——那是模型的事 |
| **执行失败自愈**：错误自动喂回模型，用 ops 协议在图上打补丁（保留人的手改）重试一次，修复过程与经验全程可见 | 自愈只修参数与连线类错误，模型服务本身不可用修不了 |
| **自主拍摄模式**：说"给你个目标你自己干"即触发——智能体连续多轮"出计划 → 自动执行（跳过确认门）→ 读自审结果修订"，直到模型确认达标 / 轮数上限 / 预算耗尽；**硬前置：必须先设单次金额上限**，没配不启动；每轮花费与停止原因全程播报，取消随时生效 | 语义级"好不好看"仍由模型自评，物理质检兜底；默认 2 轮、上限 4 轮，防烧钱失控 |
| **子进程超时保护**：ffmpeg/ffprobe 全部调用带超时（超时 kill），坏文件最多浪费几十秒，不会挂死整个执行；长轮询容忍连续 3 次网络抖动 | — |
| **分镜风险评分**：景别重复 / 运镜单一 / 动作雷同 / 时长节奏 / 台词分布 / 情绪覆盖六维启发式，确认门亮分并给具体改法 | 只查计划，不看画面效果 |
| **双方案提案**：AI 可给 A/B 两版差异化计划，确认门一键互换 | — |
| **双供应商**：视频生成 Provider 化，ARK（Seedance）与即梦（火山 CV，AK/SK）可切换；即梦不支持的能力（尾帧/多图参考/音频）按镜自动回落 ARK；即梦只支持 5s/10s 两档时长，提交前自动吸附并播报 | 即梦链路未经真实 AK/SK 实跑（签名已与参考实现对拍） |
| 开放画布：加/删节点、改连线、改参数（选中即出浮动检查器） | — |
| 可选输入折叠，多镜图能整屏可读（展开状态随工程持久化） | — |
| 流式对话 + 思考/工具调用过程呈现 | 语义级正确性：模型可能选错字段——常见错配（把 URL 填进普通字段）已有审计警告，其余仍靠人在改动清单里看 |
| 智能体 ops 协议改图（人机共用操作引擎） | — |

## 维护

项目整体可以随意移动：Rust 侧会从可执行文件位置向上寻找 `engine/`（workspace 或 prompts 任一存在即认定）
自动定位根目录；也可以用环境变量 `STORYFORGE_ROOT` 或设置页的「项目根目录」显式指定。

ffmpeg / ffprobe 随安装包分发；源码运行时从 `bin/` 读取。改提示词资产直接编辑
`engine/prompts/*.json`（风格圣经 / 分镜语法 / 负面词），保存即生效。

## 生成节点

节点实现移入了内核本体（`src-tauri/src/kernel.rs`），节点目录见 `src/lib/node-library.json`：

- `短剧 · 角色定妆`：角色锚点 → 定妆参考图（Seedream 文生图）
- `短剧 · 分镜首帧`：角色参考图 + 景别/运镜/动作/情绪 → 一张定帧
- `短剧 · 镜头视频`：首帧 + 动作/台词/时长 → Seedance 视频（同步音频）
- `短剧 · 尾帧接续`：从视频取最后一帧，供下一镜用
- `内核 · 图像生成 / 视频生成`：底层节点，保留给高级用法
- 基础节点：`EmptyImage`（占位图）、`ImageScale`（缩放）、`LoadImage / LoadVideo`（工作区 input/）、`SaveImage / SaveVideo`

生成直连 `ark.cn-beijing.volces.com`，不走 Comfy 官方代理。

## 视频与人物审核

Seedance 2.5 不接受直接上传的真人脸，也不接受把带人脸的图片重新编码后传回。
分镜首帧如果被判定“疑似真人”，`镜头视频` 节点会自动改用角色定妆图的**原始 URL**
作为 `reference_image` 重新提交：人物保持一致，但视频构图可能与首帧略有差异。
定妆图由 Seedream 文生图生成，属于平台信任素材。
