# StoryForge · 短剧工坊

对话驱动的 AI 短剧工作台。你说一句想拍什么，模型把它翻译成 ComfyUI 节点图，ComfyUI 负责执行，画面回到工作台。

> 不是"人画流程图"，是"模型写流程，人审流程"。

---

## 定位：它是生成机，不是剪辑软件

一句话：**把一句话的构想，变成一组能直接用的镜头素材。**

它管的四件事，到"素材落盘 + 交付一个文件"为止：

| 环节 | 在这台工具里 |
|---|---|
| 听懂 | 对话 → 分镜计划（镜别、运镜、台词、时长） |
| 变成能执行的图 | 画布上的节点图，人和 AI 改的是同一张 |
| 真跑出来 | ComfyUI 执行，逐镜进度、逐镜耗时、随时能停 |
| 交得出去 | 分镜板按镜看、单镜重跑、按出片顺序合成一个文件 |

它**不碰**的（判断标准只有一条：**要不要在时间轴上编辑？要，就不做**）：

| 不做 | 为什么 |
|---|---|
| 剪切 / 变速 / 关键帧 / 转场 | NLE 的活，做不过 Premiere / 剪映，做了也没人用 |
| 字幕烧录 / 音轨替换 / 混音 | 同上；要字幕就把台词导出给剪辑软件，别在这里长出一条轨道 |
| 调色 / 滤镜 / 特效 | 属于生成端（提示词、模型），不属于后期 |
| 时间轴预览 / 多轨 | 一旦出现轨道，这工具就成了"又一个剪辑软件"，定位就散了 |

边界内保留的两件事，因为它们是**排序和封装**，不是编辑：

- **出片顺序**：拖一下改镜头先后，纯排序，不产生时间轴；
- **合成成片**：把同一版的多段镜头按顺序无损拼成一个文件，省得自己回去拼。

再往上就该交给剪辑软件了——这不是能力问题，是分工问题。

## 目录

整个产品只有一个目录 `app/`：前端、桌面壳、执行内核、运行环境、文档、脚本全部在里面，不引用外部目录。

```
app/
├── src/                         前端（React + TypeScript）
├── src-tauri/                   桌面壳（Tauri + Rust）
├── engine/                      执行内核（自包含）
│   ├── ComfyUI/                 ComfyUI 0.43 源码
│   ├── venv/                    CPU torch，独立 Python 3.13
│   └── workspace/               ComfyUI base-directory
│       ├── custom_nodes/storyforge_ark/   自写节点 + prompts 资产
│       ├── input/ output/ temp/ user/     运行时数据
│       └── models/                        空目录（只走 API 节点）
├── docs/
│   ├── architecture.md          现行架构方案
│   ├── reference/               火山方舟接口参考
│   ├── archive/                 历史方案 v1 / v2
│   └── shots/                   运行截图
└── scripts/                     节点库生成脚本
```

根目录只有 `README.md`、`启动StoryForge.bat` 和 `app/`。

## 首次运行

```powershell
cd app
pnpm install
pnpm tauri dev
```

启动后在左上角点「启动」拉起 ComfyUI（CPU 模式，约 10–30 秒）。

已经构建过的话，直接双击根目录的 `启动StoryForge.bat`（优先启动 release 版，无黑框）。

完整安装包在 `app/src-tauri/target/release/bundle/`（msi / nsis）。注意：安装版装到
系统目录后无法自动找到 `engine/`，首次使用需在设置里把「项目根目录」指向本项目的 `app` 文件夹；
日常使用推荐直接用 `启动StoryForge.bat`（免安装、自动识别路径）。

## 配置模型

点右上角「设置」，两个 Key 分开填：

| 字段 | 说明 |
|---|---|
| 对话 Base URL | DeepSeek：`https://api.deepseek.com/v1` |
| 对话 API Key | `sk-...`，只存本机，用来做策划和分镜 |
| 对话模型 | `deepseek-flash`（需支持 JSON 输出） |
| ARK Key | `ark-...`，生图/生视频节点使用；改后重启 ComfyUI |
| 图像/视频模型 | 节点调用时使用的生成模型 |
| 视频分辨率 | 480p / 720p / 1080p（1080p 是 10bit H.265） |
| 同步音频 | 是否让 Seedance 生成对白 / 环境声 |
| 预算 | 单次最多镜头数、总时长上限（秒）；超限自动截断 |
| 项目根目录 | 留空自动识别；移动项目后无需改任何路径 |

ARK Key 也可以单独读环境变量 `ARK_API_KEY`，或读
`app/engine/workspace/custom_nodes/storyforge_ark/ark_key.txt`。

## 现在能做什么

- **正常聊天**：打招呼、问用法、闲聊都行，不再逼你拍片
- **多会话**：导演台左上角可切换/新建/删除对话，重启应用历史不丢（产物按端口自动重连）
- **界面手感**：导演台可拖拽调宽、`Ctrl+B` 收起；分镜看大图支持 `←` `→` 翻页、`Esc` 关闭；运行中显示阶段 + 已用时
- **流式对话**：正文边生成边显示（不等整段 JSON 落完）；`思考` 折叠成一行、点开看模型的 reasoning 原文；工具调用按步列出来（读取角色锚点 / 编译节点图 / 校验连线 / 执行 ComfyUI），每步带结果和耗时，点开看原始输出
- **失败不糊弄**：配了 Key 却调不通就直说原因（Key 无效 / 模型名不对 / 超时），不再悄悄退回占位图；设置页有「测试连接」按钮，一次最小请求验证 Base URL + Key + 模型 ID
- **对话只管说话，动手全在画布**：说一句想拍什么，模型把分镜编译成节点图直接放到画布上；你要改什么（换景别、改时长、加节点、改连线、调参数）也直接说，它自己在图上改。对话区里不摆参数、不摆确认卡
- **画布是唯一真相**：AI 改的是这张图，你改的也是这张图，执行的就是屏幕上这张图——只有画布上一个「开始生成」按钮会真的花钱，AI 不会偷偷执行
- **开放画布（M3）**：画布页是主界面，永远可编辑，不拍片也有空白画布可玩——从 394 个可执行节点里搜索添加、删除任意节点、拖端口改连线（类型自动校验）、选中节点在右上角检查器里就地改参数
- **画布照 ComfyUI 的手感做**：滚轮在指针处缩放（`Shift+滚轮` 横移）、空白拖动平移、空格/中键抓手、`Ctrl+拖` 框选、双击空白在光标处弹节点搜索（回车加第一个）、右键菜单（加节点/复制节点/断开全部连线/删除/适应画布/按数据流重排）、拖连线靠近兼容端口自动吸附并高亮、连线按类型上色、点连线 `Del` 删除、`Ctrl+A` 全选、`Del` 删选中、右下角缩放控件与适应画布
- **AI 干了什么看得见**：新节点一个个长出来（工具栏同时数「铺节点 3/5」，左下清单也跟着一条条长），改完的节点亮 7 秒并打上「AI 改」；清单（`+N 节点 / 改 N 处 / 连线 ±N`）点任意一条就把画布飞过去并选中那个节点；重新编译分镜会把整张图重铺，这时清单直接写「AI 重铺了整张图 · 旧 5 → 新 5 节点」，不让"改 3 处"掩盖整版被换掉
- **节点不糊脸**：可选输入默认收成一行「＋N 可选」（没接线也没填值的才收），点开再摊；一张视频节点从 14 行压到 9 行，多镜图也能整屏看清
- **跑不起来不许交**：AI 每次改完先过审计（必填输入接没接、终点存不存在、有没有悬空孤岛、类型对不对），不过就自己修一轮、最多两轮；还不行就整版撤回、画布保持原样，并把原因说清楚
- **点之前先自检**：「开始生成」点下去之前跑同一套审计，跑不起来直接拦下，并把出问题的那个节点指给你看（自动居中 + 选中 + 打开参数面板）
- **能停**：生成过程中按钮变成「停止」，断了引擎就走人，画布不留半成品；AI 还在想/写的时候也能停（对话区右下角方块键，或让它跑飞了按一下），掐断模型输出、这一轮整版作废、画布一个字都不动
- **生成中看得见跑到哪**：执行时接 ComfyUI 的 `/ws`，哪个节点在跑就给它一圈亮边 + 底部进度条 + 头部 `42%`，跑过的打 `✓`、缓存命中的标 `缓存`、出错的红边标 `出错`；工具栏同步显示「跑 镜头1视频 · 42%」，不用盯着「生成中」干等
- **分镜页也跟着跑**：生成时「分镜」页顶上摆的是这一版正在跑的镜像——每一镜按自己那组节点（`shot_N_*`）亮起来，跑着的显示百分比和底部进度条，跑完打勾，头上写「已完成 2/4 · 正在跑第 2 镜」；跑完才换成带成图的历史卡片
- **每镜花在哪，算得出来**：跑的时候按 `shot_N_*` 前缀把 `/ws` 事件切段，每镜记三样——**等**（上一镜跑完到这一镜开跑之间的空档）、**跑**（这一镜自己节点的墙钟）、**重**（同一节点被重复执行的次数）。分镜卡写「实耗 3.1s」，页脚一排「逐镜实耗」：灰条是等、亮条是跑，拖后腿那一镜一眼看得出来；同一节点跑了两次会打 `↻2`。只记真观测到的量，云端排队藏在节点内部，就不编造。
- **拍完还能改顺序**：分镜卡直接拖，拖完这一版的"出片顺序"就变了——卡片角标按新位置重排，被挪动的镜标上「原 03」，头上出现「出片顺序 02 → 03 → 01 → 04」和「恢复原序」。只改顺序：不重跑、不动文件、不花钱，「合成成片」按新顺序拼
- **多版并排对比**：同一个计划跑了几版，分镜页点「多版对比」把它们并排放——行是镜号、列是版本（最多三版），同一镜的几版摊在同一条横线上看差别；下面「挑版本」勾选想比的几版，点缩略图仍然能全屏看原图。
- **缩略图不靠引擎活着**：产物文件在 `output/` 里，历史里的图和视频直接从磁盘读（本地文件协议），ComfyUI 停掉、空闲自动停、重启应用之后都还能看，不再因为 `/view` 404 变成一片破图
- **引擎不会一直烧着**：跑完挂上空闲计时（默认 5 分钟，设置里可调 2/5/10/30 或关掉），到点没人用就自动停 ComfyUI 把显存还回来；下次点「开始生成」会自己拉起来，已产出的素材不受影响
- **智能体同等编辑权**：对模型说"把 #3 直接连到 #1"，它通过 ops 操作协议（add/remove/connect/disconnect/set/setMeta）直接改图——和人用同一个操作引擎；改完就停在画布上等你看，不自己执行
- **自我完善**：执行失败自动把错误喂回模型修订计划（最多 1 次），并沉淀一句经验进记忆；之后每次出计划都带着这些经验，越用越顺
- **确认门 + 预算上限**：确认卡片显示镜头数与总时长；设置里可限单次最多镜头数和总秒数，超限自动截断
- **单镜重跑**：分镜板每张卡可只重跑那一镜，不用整片重来
- **尾帧接续**：多镜时上一镜尾帧自动作为下一镜的画面衔接参考
- **用量统计**：每次执行记录用了多少 LLM token、几张图、几秒视频；资产页有累计用量
- **成片拼接（M5）**：分镜板一键「合成成片」——多镜头无损拼接（PyAV 重编码，crf18），成片自动进分镜板和资产页可直接播放；分镜卡支持删除记录、一键打开输出目录
- 短剧领域节点：角色定妆、分镜首帧、镜头视频、尾帧接续
- 没有 ARK Key 也能跑通链路：使用内置 `EmptyImage` 占位图，真实经过 ComfyUI 执行
- 节点库来自真实 `/object_info`：1027 个节点，394 个可直接执行，305 个需本地权重会被校验器拦下

## 协作模式

吸取 ComfyUI（节点即一切）和 DSH（一切皆插件/操作）的思路，人机协作建立在一个共识上：**图操作引擎只有一份**。

| | 人 | 智能体 |
|---|---|---|
| 入口 | 画布拖拽 / 节点选择器 / 参数检查器 | 对话 → ops 操作序列 |
| 能力 | 加/删节点、改连线、改参数 | 完全相同的操作集合 |
| 出口 | 画布上的「开始生成」 | 没有出口：改完就停在画布上 |

对话区只负责沟通（说需求、问问题、看思考与工具调用），一切与"生成什么"有关的东西都落在画布上。

## ComfyUI 在这里的角色

生成算力在云端（ARK 的 Seedream / Seedance），ComfyUI 本地只做三件事：接收画布那张图、派发云端节点、把产物落盘到 `output/`。

| | 不启动 | 启动 |
|---|---|---|
| 看画布、改图、让 AI 改图 | 照常 | 照常 |
| 本地节点（EmptyImage / 缩放 / 拼接） | 跑不了 | 跑（免费） |
| 云端生成（出图 / 出视频） | 跑不了 | 跑（按 ARK 计费） |
| 代价 | 0 | 常驻内存 + 显存 |

所以它只在真要执行时才需要活着：点「开始生成」会自动拉起，跑完挂空闲计时（默认 5 分钟）自动停。

## 能力边界

| 已通 | 未通 |
|---|---|
| 计划 → 改参 → 确认 → 分镜图 → 视频闭环 | 成本换算成金额（各家价格常变，只记量不记钱） |
| 开放画布：加/删任意节点、改连线、改参数（选中即出浮动检查器） | 云端排队藏在 ARK 节点内部，拆不出来 |
| 可选输入折叠，多镜图能整屏可读（摊开了哪些节点会记在本机） | 折叠状态跟机器走，不跟着图/工程走 |
| 流式对话 + 思考/工具调用过程呈现 | 语义级正确性：模型可能选错字段（如把首帧写成文件名）——静态审计查不出来 |
| 智能体 ops 协议改图（人机共用操作引擎） | 对比只能并排看，不能叠加/闪烁对比 |
| 改完自动审计 + 自修 2 轮 + 失败整版撤回 | 只看静态结构，看不出"这版好看不好看" |
| 失败自动修复 + 经验记忆沉淀复用 | 记忆手动编辑（当前可查看与清空） |
| 单镜重跑 / 尾帧接续 | 字幕 / 音轨 / 调色 / 转场——**刻意不做**，见上面「定位」 |
| 首帧被真人审核拦截时自动降级到参考图模式 | — |
| 分镜页实时镜像（逐镜进度、生成中可停） | 不能插空镜（要造一段黑场视频，属于剪辑思路） |
| 逐镜拆成「等 / 跑 / 重」（`/ws` 按镜切段） | — |
| 多版并排对比（行=镜号、列=版本，最多三版） | — |
| 拖动调出片顺序（成片按此拼接，不动产物） | — |
| 产物走本地文件协议，引擎停了历史照样能看 | — |

## 维护

修改自定义节点后，重建前端节点库（ComfyUI 需先启动）：

```powershell
cd app
pnpm nodes
```

项目整体可以随意移动：Rust 侧会从可执行文件位置向上寻找 `engine/ComfyUI/main.py`
自动定位根目录；也可以用环境变量 `STORYFORGE_ROOT` 或设置页的「项目根目录」显式指定。

## 自定义节点

`app/engine/workspace/custom_nodes/storyforge_ark/`：

- `短剧 · 角色定妆`：角色锚点 → 定妆参考图（Seedream 文生图）
- `短剧 · 分镜首帧`：角色参考图 + 景别/运镜/动作/情绪 → 一张定帧
- `短剧 · 镜头视频`：首帧 + 动作/台词/时长 → Seedance 视频（同步音频）
- `短剧 · 尾帧接续`：从视频取最后一帧，供下一镜用
- `StoryForge · 图像生成 / 视频生成`：底层节点，保留给高级用法

节点直连 `ark.cn-beijing.volces.com`，不走 Comfy 官方代理。

## 视频与人物审核

Seedance 2.5 不接受直接上传的真人脸，也不接受把带人脸的图片重新编码后传回。
分镜首帧如果被判定“疑似真人”，`镜头视频` 节点会自动改用角色定妆图的**原始 URL**
作为 `reference_image` 重新提交：人物保持一致，但视频构图可能与首帧略有差异。
定妆图由 Seedream 文生图生成，属于平台信任素材。
