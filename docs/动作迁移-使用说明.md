# 动作迁移（舞蹈复刻）使用说明

把一段参考视频里的动作，搬到指定人物形象上。内核走阿里云百炼 `wan2.2-animate-move`。

---

## 一、前置：两个 Key 都要配

| Key | 用途 | 缺了会怎样 |
|---|---|---|
| ARK Key | 生成古风定妆图（Seedream） | 定妆节点直接失败 |
| 百炼 API Key | 动作迁移（wan2.2-animate-move） | WanAnimate 节点报「未配置百炼 API Key」 |

百炼开通（四步）：

1. 阿里云账号完成实名认证。
2. 打开 <https://bailian.console.aliyun.com/>，开通百炼（模型服务）。
3. 控制台右上角「API-KEY」→ 创建，复制 `sk-` 开头的 Key。
4. 工具「设置 → 动作迁移 · 百炼」填进去。地域域名留空即为北京；Key 与地域必须一致，跨地域必然鉴权失败。

新账号自带 **50 秒免费额度**（90 天有效，std/pro 共用），够验 2 次 20 秒小样。

## 二、这单的操作路径（分两步，画布一直留着）

画布是持久工作台：关掉应用再打开，那张图和已经出的结果都还在，随时接着干。

**第一步：只出参考图，不跑视频**

1. **放素材**：设置 →「存储位置」里点素材目录旁边的「这里打开」（默认是安装目录下的 `input\`），把甲方的 20 秒舞蹈视频（如 `dance.mp4`）和人脸参考图（如 `face.jpg`）放进去。文件名只用英文数字，中文名会被转义。
2. **对话**：
   > 先给我出古风定妆图和背景图看看。用 face.jpg 这张脸，浅蓝汉服造型，背景放在云海仙山之巅、淡青薄雾。
3. **看画布**：铺出四个节点——`空镜背景 → 保存背景`、`人物参考 → 定妆（全身 + 场景）→ 保存定妆`。
   这一步图里**没有动作迁移节点**，所以就算点了「开始生成」，也只花两张图的钱（约 0.6 元）。
4. **看图**：背景和定妆图都在资产页/画布上，不满意就直接说「背景再飘一点雾」「衣服换成月白」，它改完重出。

**第二步：满意了再跑视频**

5. **对话**：
   > 可以，用刚才那张定妆图跑视频，先把参考视频截到 5 秒试一下。
6. 模型会把上一轮的定妆图文件名填进 `characterImage` 复用——**不重新生成定妆图**，你刚看过的那张不会作废。画布上换成 `复用定妆 → 动作迁移 → 保存成片`。
7. 5 秒小样看完没问题，再说「放全 20 秒、用 wan-pro」，跑终稿。

> 如果想一次到位（不先看图），直接说「跑 20 秒」也行，模型会直接出完整图。但按经验，先看图能省掉最贵的那次返工。

## 三、背景怎么做（这单的关键）

先记一条模型行为，它决定整个做法：

> **wan2.2-animate-move 的成片背景来自人物图，不是参考视频。**
> 对比：animate-mix 才是保留视频场景的那种（换人不换景）。

所以换背景**不需要抠像、不需要额外 API、不多花一分钱**——只要让人物图里那个人一开始就站在古风场景里。工具里的链路是：

```
空镜背景（DramaBackdrop，无人） → 落盘 motion_bg_*.png
        ↓ 作为场景参考
定妆图（人脸参考 + 场景参考）→ 人物站在该场景中的全身照 → 落盘 motion_char_*.png
        ↓
动作迁移 → 成片背景 = 定妆图的背景
```

对话时只要把场景说具体，模型会填进 `scene` 字段：

> 场景写「云海翻涌的仙山之巅，淡青薄雾，远处楼阁若隐若现，晨光侧照」

- `scene` 留空 → 不生成背景节点，定妆退回纯色/文字描述，成片背景由模型自由发挥。
- 背景图单独落盘是有意的：同一项目多镜头复用它，场景才不会一跳一跳。
- 空镜图里绝不能有人（内核的负面词已经把「人物/人影/肖像」压掉了）。

**兜底方案（当前未内置）**：若实测发现背景仍不对（比如模型把场景画糊了），把 anchor 改成「纯绿幕背景」再跑一次，成片就是绿幕视频，用 ffmpeg 抠到任意古风图上——边缘更干净、背景完全可控，代价是要多做一次调色对齐。需要时再加，别提前上。

## 四、5 秒小样要盯三件事

| 要看的 | 判断标准 | 不行怎么办 |
|---|---|---|
| 白模能不能驱动 | 人物跟着动、肢体没崩 | 把动迁节点的 `check_image` 关掉再试 |
| 背景是不是那个场景 | 出来的是仙山云海，还是灰棚 | 灰棚 = 定妆没吃进场景，把 scene 写具体、重跑定妆 |
| 人物像不像 | 脸与服装接近甲方那张 | 换参考图、补服装细节、或改半身构图 |

这三条决定后面怎么做，**别跳过小样直接跑 20 秒**。

## 五、成本

只按成功输出的秒数计费，输入不计费，失败不扣钱。图片按张。

| 档位 | 分辨率/帧率 | 单价 | 20 秒一片 | 5 秒小样 |
|---|---|---|---|---|
| wan-pro | 1080P / 25fps | 0.6 元/秒 | 12 元 | 3 元 |
| wan-std | 720P / 15fps | 0.4 元/秒 | 8 元 | 2 元 |

另加两张图：空镜背景 ≈0.30 元、定妆图 ≈0.32 元（含两张参考图）。一次完整跑片 ≈ 12.6 元（pro）。

北京地域价（新加坡约为 2.2 倍）。40 元预算 = 免费额度打底 + 3 次 pro 或 5 次 std 迭代。

工具里的确认门会显示「预计 ¥X（含重试缓冲至多 ¥Y）」，预算上限在「设置 → 预算」里设 `cap` 模式即可硬拦。

## 六、已知风险

| 风险 | 现在的处理 |
|---|---|
| 白模没五官，人脸检测可能不过 | `check_image` 可关；关掉后靠人体关键点驱动，效果需实测 |
| 甲方参考图是半身，参考视频是全身 | 定妆节点会扩成全身，下半身是模型补的，服装一致性靠 anchor 文字兜；最好让甲方补一张全身照 |
| 背景由人物图决定 | move 保留人物图背景，所以场景靠 scene + 定妆吃进去；场景画糊了就重跑背景图，不走合成 |
| 20 秒长片尾部崩 | 模型上限 30 秒，长片一致性会下滑；可降 std 先出节奏版 |
| 真人参考图触发内容审核 | 报 `IPInfringementSuspect` / `DataInspectionFailed`，换图或改由 Seedream 生成的定妆图当输入 |
| 临时素材 48 小时过期 | 产物已落本地产物目录（默认 `安装目录\output\`），不受影响；只有任务重投需要重新上传 |

## 七、内核改了哪些（给后续维护）

| 位置 | 改动 |
|---|---|
| `src-tauri/src/kernel.rs` | `WanAnimate` / `VideoFit` / `DramaBackdrop` 节点、`ds_upload`（getPolicy + OSS 直传）、`ds_task`（异步轮询）、万相计价、`find_asset`（input/ → output/ 递归查找） |
| `src-tauri/src/lib.rs` | 配置项 `bailian`、`comfy_input_dir` / `comfy_input_list` 命令 |
| `src/lib/plan.ts` | `mode: "motion"` 计划解析 + `compileMotionPlan` 编译器 |
| `src/lib/agent.ts` | 动作迁移提示词、素材清单注入、百炼 Key 缺失提醒 |
| `src/lib/node-library.json` | 新增 `WanAnimate`、`VideoFit`；`DramaCharacter` 加 `reference_image` |
| `src/components/SettingsDialog.tsx` | 百炼 Key 与地域配置、存储位置（产物目录可改 + 一键搬旧产物）、素材目录入口 |
| `src-tauri/src/kernel.rs`（断点续跑） | `run_dir` / `node_signature`（输入指纹）、`persist_node_outputs`（节点产物即时落盘）、`cache_store` / `cache_restore`、`node_must_run`（强制重跑连带下游）、`kernel_submit` 新增 `force_nodes` |
| `src/lib/runArtifacts.ts` | `_run` 文件名 → 节点产物的纯映射（好单测） |
| `src/components/CanvasGraph.tsx` | 节点底部缩略图 + 大图预览 + 工具栏「重跑」 |

关键实现点（改的时候别踩回去）：

- 百炼调用必须带 `X-DashScope-OssResourceResolve: enable`，少这个头 `oss://` 地址直接报错。
- 本地素材一律先上传换 `oss://`，不要赌跨云拉取别人的 URL。
- 视频硬限制：2~30 秒、边长 ≤2048、≤200MB；超了在发送前就拦住，别花钱买失败。
- 成本对账读的是视频真实时长（`ffprobe`），不是估算值。
- 「先看图再跑视频」靠两件事：`stage=stills` 让图里根本没有 WanAnimate 节点；`characterImage` + `find_asset` 让第二轮直接读上一轮的产物。别改成重新生成定妆图——那会让用户刚看过的图作废。
- 强制重跑一个节点，必须把它的下游一起标脏（`node_must_run`）。只重跑自己、下游还吃旧缓存的话，画布上会出现「新图配旧成片」。
- `_run` 里那份是画布用的现场副本（`metadata.live = true`），不能进 `collectAssets`、也不能进清理候选，否则分镜页重复计数、清理还会把画布擦空。
- 指纹只认内容不认时间：同一张图重复提交必须命中缓存，否则「暂停—继续」就是假的。

## 八、随时停、随时接着跑

画布是工作台，不是一次性任务。做到一半想停就停，回头接着干。

### 停

点工具栏「停止」。粒度是**节点之间**和**轮询周期之间**：

| 正在跑的东西 | 停下来的时机 | 已经花掉的钱 |
|---|---|---|
| 出图（Seedream） | 请求返回即止 | 该张图照扣 |
| 视频（Seedance / 即梦） | 下一个轮询（5 秒） | 云端任务照扣，这片不再下载 |
| 动作迁移（百炼） | 下一个轮询（15 秒） | 同上 |

所以：**图可以随时停，视频尽量等它跑完再停**——视频提交出去的那一刻钱就已经花了，停在中途等于白花。

### 接着跑

每个节点一跑完，产物立刻写进产物目录下的 `_run/{节点id}.png|mp4`，并贴在画布节点底部。停之后：

1. 已完成的节点，缩略图还在，点开能看大图（Esc 关闭）。
2. 再点「开始生成」：输入没变的节点直接复用，日志里写「复用上次结果（输入没变，跳过执行）」，只跑剩下的。
3. 关掉应用、隔天再开：产物从 `_run` 扫回画布，一个不少。

### 重跑

- 工具栏「重跑」= 不吃缓存，整张图重来（钱重新花）。
- 分镜页「重跑这一镜」= 只重跑那一镜，也不吃缓存。
- 改了某个节点的参数 → 它和它的下游自动失效，上游不动。这是省钱的默认行为，不是 bug。

### 缓存在哪、怎么清

产物目录下的 `_run/cache.json` 记的是「输入指纹 → 产物文件」。删掉这个文件等于让工具忘掉一切（产物文件本身不删），下次全部重跑。`_run` 目录里的文件就是画布上贴的那些图/片，删了画布会空，但正式产物（`storyforge/` 下带自增序号的文件）不受影响。

换产物目录：设置 →「存储位置」→ 产物目录填新路径（可以直接填 `D://...`），点「把现有产物搬过去」，再保存。搬运不覆盖同名文件。
