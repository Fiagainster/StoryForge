
## 换内核：抛弃 ComfyUI，改用原生 Rust 执行内核

背景：用户质疑 venv 1.7GB（torch 539MB 等）只为调 API 服务，拍板"那就换内核"。
确认关键参数：纯 Rust 原生内核 + ffmpeg 打包进安装包（~110MB vs 原 1.7GB，瘦 15 倍）。

已完成：
- `src-tauri/src/kernel.rs`（~1300 行）：图解析/校验/拓扑执行器；12 节点白名单
  （DramaCharacter/DramaShotFrame/DramaShotVideo/DramaContinuity/StoryForgeSeedream/StoryForgeSeedance/
   SaveImage/SaveVideo/EmptyImage/ImageScale/LoadImage/LoadVideo，目录外拒收）；
  ARK 两接口移植（文生图 data URL、视频任务轮询 5s/25min/首帧审核降级重试）；
  ffmpeg 杂活（lavfi 占位图、scale、-sseof 抽尾帧、concat 拼接、ffprobe 时长）；
  事件 `kernel://event` 形状对齐 ComfyUI /ws；kernel_history 形状对齐 /history。
- lib.rs：env_check 重写（ffmpegReady/nodesInstalled=提示词）、comfy_status 恒真（常驻）、
  comfy_stop=kernel_interrupt、assemble_shots 改走 ffmpeg、is_product_root 改判 engine/workspace|prompts、
  kernel_submit_cmd 包装（从配置读 Key/路径）。cargo check 干净。
- 前端：comfy.ts 重写为内核客户端（类名保留 ComfyClient，agent/store 零改动）；
  store.ts start/stop/ensure/idle 全部改语义（内核常驻、停止=中断执行、空闲自动停退役）；
  node-library.json 换成 12 节点内核目录；nodeSearch CORE 收敛；StatusBar/SettingsDialog/文案去 ComfyUI 化。
- 提示词资产迁到 engine/prompts/（内核运行时读取，缺省回退内置）。
- .gitignore 加 app/bin/ 与 app/src-tauri/bin/（90MB 二进制走 Release 分发）。
- 20 个单测全过，tsc 全绿。
