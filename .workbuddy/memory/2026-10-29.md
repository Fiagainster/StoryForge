## StoryForge 前端视觉重做（对齐 DSH 语言）

背景：用户反馈"很多地方不够丝滑，没有 deepseek harness 前端那种简约美感"。

诊断（已核对代码与截图）：40+ 处硬编码 hex、surface 明度差 1–2% 靠描边分层、字号碎成 8.5–13px 七档、amber 强调色滥用、消息四边框气泡、440px 写死不可拖、空态两行灰字、长任务只有一个圆点无计时。

参照物：`D:\Project\智慧公安管理Agent\deepseek-harness\packages\client`（ui-theme/base.css、ui-primitives/Button|Tag|Toast、ui-chat/ChatView|MessageItem）。提炼规则：0.5px 发丝线、14px 基准字（13/12/11 阶梯）、surface 明度阶梯代替描边、单一强调色、100–200ms 只在 opacity/translate、聊天列 + 悬浮输入卡。

改动：
- `src/styles.css` 全量重写为 token 层（surface 5 档 / line 3 档 / fg 4 档 / accent 单色 #e0b166 / r-1..5 / --ease 170ms），组件类 btn|field|tag|card|popover|tab|kbd|skeleton|dotgrid 放 `@layer components`
- 新增 `src/components/ui.tsx`：Btn / IconBtn / Tag / Spinner / Skeleton / Empty / 内联图标 I.*
- `App.tsx`：可拖拽分栏（340–640，localStorage 记忆）、Ctrl+B 折叠、顶部 toast、Esc 关设置
- `StatusBar`：收敛为品牌 + 引擎 + 模型 + 仅异常时才出现的告警 tag
- `ChatPanel`：助手无气泡纯文本、用户 16px 圆角气泡、会话下拉 popover、hover 复制、吸底滚动 + 回到底部、运行计时 mm:ss、计划卡重排
- `Workspace`：下划线 tab、auto-fit 分镜栅格、右侧 xl 侧栏（风格/角色锚点/用量）、灯箱 ←→/Esc、空态引导
- `CanvasGraph` / `SettingsDialog`：套用同一套 token 与组件类
- 验证：`pnpm build` 通过；用「无头 Chrome + 临时 preview 入口 + Tauri invoke 打桩 + 假分镜数据」截图逐屏核对（临时文件已删除）

- 无头 Chrome `--screenshot` 必须传 Windows 绝对路径，相对路径报"系统找不到指定的路径"

- 视觉验收数据不要写进正式入口：临时 `preview.html` + `src/preview.tsx` 打桩 `window.__TAURI_INTERNALS__.invoke`，用完即删
